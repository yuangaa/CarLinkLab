# NioPlay 车机 16:9 音乐界面 —— 使用说明

## 一、这次做成了什么

在**天空视窗**里，让**手机应用以真正的 16:9 横屏铺满车机屏**，并用它做 Apple Music 的**车机端界面**：

| 能力 | 状态 |
|---|---|
| 16:9 横屏铺满（不再是 9:16 竖条） | ✅ 实测 `cur=3024x1696` |
| 触摸操作（映射正确，非错位） | ✅ 注入测试命中并触发控制 |
| 读取正在播放（曲名/歌手/专辑/封面） | ✅ `NOW: Leaves (The Rose OST) — 阿桑` |
| 播放队列（101 首，可滚动） | ✅ `queue=101` |
| 传输控制（⏮ ⏯ ⏭ + 进度条拖动） | ✅ |
| **无损音质** | ✅ 音频仍由 Apple Music 自己输出 → 座舱音响 PCM |
| 手机自己的屏幕 | ✅ 不受影响（只在车机显示器上请求横屏） |

## 二、原理（为什么这次能成）

1. **天空视窗的虚拟显示器跟随"前台应用请求的方向"**（它的 flag 是 `FLAG_ROTATES_WITH_CONTENT`）。
   - 视频软件全屏播放时能横屏，就是这个机制。
   - **不能**事后用 `wm size` 强改尺寸 —— 那会让输入变换错位（实测 `2.03×` 缩放，点不准）。
2. **SkyLink 的方向管理器**会把应用判成三种之一：
   - `landscape` 类应用 → 交给我们（"user"，跟随显示器旋转设置）
   - Apple Music（清单是 `behind`）→ **强制竖屏**
   - 于是**显示器朝向 = 该显示器的"用户旋转"设置**
3. 所以：**把车机显示器的用户旋转设为横屏** → 我们的应用就是 16:9 满屏。

## 三、一次性设置（已在你这台机器上执行）

```bash
# 车机（天空视窗）显示器：横屏 + 车机平板密度
adb shell wm user-rotation -d 90000005 lock 1
adb shell wm density      -d 90000005 600

# 如果哪天被重置了，重新执行上面两条即可
# 恢复竖屏:  adb shell wm user-rotation -d 90000005 lock 0
```

> 该设置按显示器的**唯一 ID** 保存在 WindowManager 里，天空视窗关闭重开、手机重启后仍然有效。

## 四、车机上怎么用

1. 天空视窗里打开 **NioPlay**（或「车机音乐（横屏）」入口）
2. 得到 16:9 双栏界面：
   - **左栏**：封面 + 曲名 + 歌手 · 专辑 + 进度条 + ⏮ ⏯ ⏭
   - **右栏**：播放队列（点任意一首）
3. 音乐选择仍在手机上（Apple Music 内部选歌）—— 界面负责显示与控制。

## 五、NIO Link 跨端伪装（第二个身份）

已安装一个**伪装成白名单跨端应用**的版本：

```
包名: com.oumi.utility.media.hub   （SkyLink 白名单 cross_dev_app 中的 VidHub，minVer=84）
版本: 100（高于 minVer，绕过版本校验）
内容: 与 NioPlay 完全相同（含 16:9 音乐界面）
APK : DiPlay-build/NioLink-CrossApp-vidhub.apk
```

**目的**：SkyLink 按**包名**判定"跨端应用"，白名单内应用在车机上获得「完美适配」的原生级体验。
**请你在车机上找找**是否出现了一个新的原生应用入口（可能显示为 VidHub 或 NioPlay）。

其他可选的伪装包名（同样未安装、`screenType=7`）：
`com.zxscnew`(中信证券) / `com.cmcc.cmvideo`(咪咕视频) / `air.tv.douyu.android`(斗鱼) / `com.hundsun.winner.pazq`(平安证券)

重新构建伪装版：
```bash
./gradlew :mobile:assembleRelease -PnioCrossPkg=<包名> -PnioCrossVer=<版本号>
```

## 六、已知待打磨

- 一次注入触摸会触发多次点击（待确认是 SkyLink 注入回声还是实现问题；真机触摸可能正常）
- 队列外跳转 `seekTo(index)` 对 Apple Music 不生效（建议用 ⏮⏭ 走队列）
- 封面为网络下载（Apple Music 提供的 512×512 图），首次显示有短暂延迟

## 七、Android Auto 结论（已查证）

- 车机未实现 Android Auto 车机端协议，手机无法向它投射 AA ❌
- Google 已**下线**「Android Auto 手机屏幕模式」([How-To Geek](https://www.howtogeek.com/google-killed-android-auto-for-phones-but-you-can-bring-it-back-with-an-app/)、[Wccftech](https://wccftech.com/android-auto-for-phone-screens-officially-comes-to-an-end/))，恢复需 root/Magisk
- 本机 Google 生态齐全（Play 商店 + GMS 25.08.32 + 已登录账号），但缺车机端支持，AA 仍无法落地
