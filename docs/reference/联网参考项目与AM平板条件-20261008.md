# 联网参考与准备建议（2026-10-08）

## 最重要的新证据
AM++源码TabletModeQualifier读目标包资源bool/is_tablet，并额外要求横屏。核对本地tmp/applemusic/base.apk（6.5.2/1586）aapt2资源输出：bool/is_tablet默认false，sw600dp=true。横屏宽度w>600不等于最小宽度sw>=600。
现有车机16:9配置sw452dp，不能仅凭横屏称平板模式；NIO Link助手sw862dp说明画布够大，但原版AM并没有成功进入。临时对手机全局提高sw会触发SkyUI桌面Taskbar路径缺类，不继续该方法。
资源证据摘录：data/reference-projects-20261008/am-tablet-resource.txt。

## 可参考的项目
1. AM++ https://github.com/Zennmn/AM-plus-plus
固定源码2ce0adf4aeca5143ac83e865df006f3f56866248。LegacyTabletQualification.kt是平板判定入口，NativeArtworkContract可参考原生封面布局。运行需要libxposed兼容框架；本机无root，不能当作直接安装可用方案。项目代码不解决SkyUI跨包启动拦截。
2. Android Display Extend https://github.com/jqssun/android-display-extend
固定源码bbbeb16e9ca1908031c9eed1a7bd25e7996065a8。ChangeRotation.java组合ignoreOrientationRequest + fixedToUserRotation + freezeDisplayRotation；跨屏无障碍浮层用createDisplayContext。Shizuku桥接标准系统接口，没有NIO专用绕过证据。我们可参考实现与恢复流程，但不改车机尺寸。
3. SecondScreen https://github.com/farmerbb/SecondScreen
配置档、尺寸密度与恢复管理可参考；项目明确不保证厂商ROM，不能当SkyUI兼容证明。
4. AOSP CTS AccessibilityOverlayTest https://android.googlesource.com/platform/cts/+/master/tests/accessibilityservice/src/android/accessibilityservice/cts/AccessibilityOverlayTest.java
系统跨屏浮层测试可参考；不证明方向请求在SkyUI会生效。

## 下步有价值的准备
- 优先核对AM运行中的真实sw、资源平板条件与原生封面布局，而非盲换更多包名。
- 多显示器标准旋转可以研究Shizuku集成（shell权限等级，不能当root）；已有电脑可回滚方案先实车验证。
- 调研独立虚拟显示器模拟（例如scrcpy new-display），避免改默认手机显示器；已用scrcpy 5.0独立虚拟屏完成三档实测，见下节。
- 所有网络参考与本机实测必须分别标记；不承诺开源项目解除NIO白名单和code102。

## 独立虚拟屏实测（00:16前后）
工具：官方scrcpy 5.0便携包，关闭虚拟桌面/系统装饰，不改手机默认显示器。退出自动销毁。录制、配置和抽帧在data/am-virtual-display/。
- 3024×1696/450：AM实际sw603dp、w1075/h603dp、land，画面横向铺满，底栏并列导航和迷你播放器；达到本机AM平板资源条件。播放页仍需逐项核对，不能只凭sw宣布封面修复。
- 3024×1696/600：即使虚拟显示器锁rotation0，AM窗口仍居中竖屏951×1696、sw254dp，显示器横屏不等于AM横屏。
- 3232×3248/600：AM实际sw862dp，画面大幅铺满，方向port（近方形），不是16:9。独立模拟屏可启动AM，不代表SkyLink90000001也放行。
- 所有模拟屏已销毁；默认屏1440×3200，无尺寸覆盖。模拟未经过车机音频路径，不能替代音频/DRM验收。
重复：python3 tools/simulate-am-virtual-display.py phone|tablet|nio|all。需要adb与本地便携scrcpy目录。
备用车内旋转脚本增加fixed-to-user-rotation enabled，并备份恢复原值；断车时拒绝修改已验证，真实90000005效果待实车。

播放页实测：tablet-player.png显示16:9平板条件下仍是右侧播放器面板，封面仍裁切；因此提高sw没有解决我报告的封面问题。phone.png的10秒抽帧为黑，窗口配置可读，不宣称该档画面正常。

近方形播放页nio-player.png：播放器是右下浮面板，封面相较16:9更完整，但仍不能说车内已修复。真实NIO跨端启动拦截仍未解除。最终dumpsys display没有scrcpy临时屏，手机辅助服务仍启用。
