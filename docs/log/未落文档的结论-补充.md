# 旧结论纠错：公开技术摘要

本页为公开版重新整理的结论，原始派单、私人操作对话和逐时记录留在本地。

## 0. 作废实验

旧 `car-orientation-test.sh` 目标显示器选择不当，shell 跨显示器启动被 code=102 拦截；私有 dumpsys 命令入口不可达且受 root 限制。脚本已阻止执行，勿重跑。

## 1. 窗口类型纠错

“只有 CarPlayHostActivity 能拿到 mWindowType=6”没有干净复现，不当作既定事实。部分日志中的当前投屏包名与当前投屏队列是运行时字段，不是另一份静态白名单。

## 2. NioPlay 显示落点

NioPlay 曾全程在 90000005 以 3024×1696 横屏运行；同窗口内的 90000001 曾属于 YouTube。显示 ID、窗口类型和画布几何须分别核对，不能互相替代。

## 4. 后续路线与边界

按白名单包名占位的精简壳是实验路径，不等于修改系统名单；曾发生 NIO Link 闪退，不能承诺可用。后续 AM 助手桥接另有实车结果，见 [实车验证摘要](../VERIFICATION.md)。
